Style guide

Every screen uses the same layout: a page title, Beary's note, then sections. Each section has its title outside and above the card. Daily check-in is the reference screen.

Screen template

Use this for every screen: Home, Check-in, Patterns, Resources, Prepare and Settings. Build new screens from it too.

  • Side padding40px from the screen edge to the content on phones. The nav bar and chat box sit 28px in.
  • Top40px above the page title.
  • Title → note24px under the page title, or under a back-arrow header.
  • Note → first section32px.
  • Section → section48px between the bottom of one card and the next section title. This bigger gap separates the groups.
  • Title → card12px between a section title and its card, measured from the title text. The small gap keeps them reading as one group.
  • Inside a card24px padding. 16px between things inside the card.
  • TitlesAlways outside the card, never inside it. Uppercase, 15px, Nunito Bold, letter spacing 0.08em. Use the category color when the section has a category, and accent blue when it doesn't.
  • Show / HideSections the person might want to tuck away get a Show/Hide control on the right of the title. When a section is hidden, its card shrinks to a one-line summary with a chevron. Every section starts open.
  • BottomLeave room so the last card can scroll clear of the floating nav bar.

Type

Nunito is the only typeface. Its rounded letters match Beary's soft illustration. Headings use ExtraBold, body text Medium, and buttons Bold.

Buttons

All buttons are pills and at least 44px tall. Each card gets one main action.

Prepare Add a visit 7 days Week
  • MainA dark navy pill. Use it for the one main action in a card.
  • SecondA light pill with a soft blue outline. Use it next to a main action.
  • SelectedOne look everywhere: a pearl-white pill with a soft shadow, ink text, ExtraBold. It works next to every mood and category color. Use it for the chosen pill, day, range, chart toggle and the current tab in the nav bar. Category colors are never used to show selection.
  • TodayThe Today day card is always ExtraBold. When another day is chosen, Today keeps a white ring.
  • UnselectedA see-through white glass with white text. This covers pills, day cards and arrows. No navy fills.
  • Helper textKeep it to a minimum. Only add a line if someone would be stuck without it. Keep it to one short sentence. Keys can use shorthand like "Dashed = no entry."
  • Beary's bubblesUse the card blue with a small corner pointing toward Beary. Label them BEARY in small accent-blue capitals. The person's own chat bubbles are accent blue with ink text.
  • IconsWhite line icons in a 44px glass circle. Never use emoji or text characters as icons.
  • NumbersA number you can change, like hours slept or minutes of exercise, opens a scroll-wheel picker when tapped.

Beary

  • ArtOnly the original illustration. No redrawn faces, poses or props.
  • ToneCalm and plain. Nothing gamified: no streaks, confetti or badges.
  • MotionGentle only: slow snowfall, a small float. Respect reduced motion.
